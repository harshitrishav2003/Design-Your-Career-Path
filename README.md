# Design Your Career Path - Resume Maker

**URL:** [https://designyourcareerpath.in/](https://designyourcareerpath.in/)

## 🚀 Overview

**Design Your Career Path** is a web-based resume maker that allows users to input their details and generate professionally formatted resumes in PDF format. Built with precision and customization in mind, it utilizes **LaTeX** for high-quality PDF rendering, providing users with real-time previews and seamless user experience.

## 🛠 Tech Stack

- **Frontend:** React.js, Material UI
- **Backend:** Node.js, Express.js
- **PDF Generation:** LaTeX
- **Deployment:** [designyourcareerpath.in](https://designyourcareerpath.in/)

## ✨ Features

- 📄 **LaTeX PDF Generation**  
  Dynamically renders user input into LaTeX templates for high-quality, print-ready resumes.

- 🧑‍💻 **Customizable Templates**  
  Users can customize resume content (education, experience, skills, etc.) in an intuitive form-based interface.

- ⚡ **Real-Time Preview**  
  Instantly see how your resume will look while editing.

- 🎨 **Modern UI**  
  Built with React and Material UI for a clean, responsive, and user-friendly design.
